# Análise de Usuários em Python

Projeto simples em Python que analisa uma lista de usuários e separa em:

- Autorizados (idade >= 18)
- Bloqueados (menores de idade)
- Sem idade informada

## Tecnologias usadas
- Python

## O que o código faz
- Percorre uma lista de dicionários
- Verifica idade
- Organiza os usuários em listas
- Conta totais
